Corte BrCAST

LEPAC

Interpretação de antibiograma segundo o BrCAST. Digite os valores de CIM e saia com a interpretação colorida, pronta para copiar no laudo. 31 microrganismos, 408 antimicrobianos, um arquivo só.

Baixar o programa Abrir agora Como usar

Sem instalação

É um arquivo HTML. Baixa, dá duplo clique e funciona — sem servidor, sem banco de dados, sem internet obrigatória. Copiar para outro computador é a instalação inteira.

Nenhum dado de paciente sai da máquina

Os CIM digitados ficam no navegador de quem digitou. O programa não envia resultado para lugar nenhum.

Os cortes ficam iguais em todos os computadores

Os valores de corte vêm de uma planilha do Google que o laboratório mantém. Sem isso, cada máquina teria a própria cópia e elas divergiriam em silêncio — a mesma cepa interpretada de dois jeitos, sem ninguém perceber.

  1. Na tela Fonte dos cortes, clique em Gerar CSV para o Drive
  2. Suba no Drive e abra com Google Planilhas
  3. Formate as colunas de corte como Texto simples
  4. Compartilhe como Qualquer pessoa com o link · Leitor
  5. Cole o endereço na tela Fonte dos cortes
Ao abrir por este endereço, o programa vem com os cortes de fábrica (BrCAST 2024) e sem planilha configurada — dá para experimentar à vontade. O que você digitar aqui fica só no seu navegador.
