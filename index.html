Corte BrCAST

LEPAC

Você digita os valores de CIM do antibiograma. O programa devolve a interpretação colorida — sensível, aumentando exposição ou resistente — pronta para copiar no laudo. Segue o BrCAST.

Como você quer usar

Só experimentar

Abre agora, aqui mesmo. Não coloca nada no seu computador.

Abrir
Deixar no computadorRecomendado

Cria um ícone na área de trabalho, como qualquer outro programa. Depois abre mesmo sem internet, e quando sai uma versão nova ele se atualiza sozinho — ninguém precisa baixar de novo.

Levar num pendrive

Guarda um arquivo só. Serve para copiar em outro computador, mandar por mensagem, ou usar em máquina que não tem internet nenhuma.

Baixar

O botão de instalar não apareceu

Ele só aparece quando dá para instalar de verdade. Os motivos mais comuns:

  • Já está instalado neste computador. Procure por Corte BrCAST no menu Iniciar, no Launchpad ou na área de trabalho.
  • É uma janela anônima. O Chrome não instala programas em janela anônima. Abra esta página numa janela normal.
  • É o Firefox. Ele não instala programas assim. Use o Chrome ou o Edge. No Safari do Mac, o caminho é Compartilhar ▸ Adicionar à Dock.

No Chrome também dá para instalar pelo menu, sem o botão: três pontinhos no canto superior direito ▸ Transmitir, salvar e compartilhar ▸ Instalar página como app.

Se nada disso funcionar, use o Baixar acima. O arquivo faz exatamente a mesma coisa — só não se atualiza sozinho.

O que é bom saber

Nada do paciente sai daqui

Os valores que você digita ficam no seu computador. O programa não manda resultado para lugar nenhum.

Todo mundo interpreta igual

Os valores de corte vêm de uma planilha que o laboratório mantém. Assim os computadores não divergem entre si — a mesma bactéria, o mesmo antibiótico e o mesmo resultado, em qualquer máquina.

Abrindo por esta página, o programa já vem com os cortes de fábrica (BrCAST 2024) e sem planilha ligada. Dá para experimentar à vontade.

A conferência continua sendo sua

É uma ferramenta de apoio. Quem confere e quem responde pelo resultado liberado é o profissional responsável.

Para quem cuida da planilha de cortes
  1. No programa, abra Fonte dos cortes e clique em Gerar CSV para o Drive
  2. Suba o arquivo no Google Drive e abra com Planilhas
  3. Formate as colunas de corte como Texto simples
  4. Compartilhe como Qualquer pessoa com o link · Leitor
  5. Cole o endereço de volta na tela Fonte dos cortes

O passo a passo completo, com o que fazer quando algo não bate, está em github.com/eacarva/corte-brcast.
